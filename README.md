# כרטיס דיגיטלי — Itzik Iluz / Innovation to Execution

דף סטטי יחיד (`index.html`), ללא build, בעיצוב תואם ל-inno2ex.com.

## לפני פרסום
1. **פרטי קשר** — באובייקט `CONTACT` בתחתית `index.html` (שדה ריק = הכפתור מוסתר), ובבלוק `.details` במקטע יצירת הקשר. חסר: קישור LinkedIn וקישור לתיאום פגישה.
2. **תמונה** — `assets/photo-cutout.png`, חיתוך שקוף מתמונת הפרופיל. להחלפה — לשמור PNG שקוף באותו שם.
3. **צבעים** — הוגדרו לפי ערכי ברירת המחדל (`--blue: #1E3A5F`); אם קודי האתר שונים, לעדכן ב-`:root`.

## איש קשר (vCard)
`assets/itzik-iluz.vcf` — שם מלא, טלפון, אימייל, תפקיד, אתר ותמונה. כפתור "שמירת איש קשר" (ב-Hero ובמקטע יצירת הקשר) מוריד אותו, והטלפון מציע "הוסף לאנשי קשר".
בשינוי פרטים — לעדכן גם את הקובץ הזה וגם את `CONTACT` ב-`index.html`.

## הצגה ללקוח
- כפתור **QR** בראש העמוד ו**הצגת QR** במקטע יצירת הקשר — מציגים קוד שמוביל לכתובת הכרטיס. הלקוח סורק במצלמה.
- **שיתוף הכרטיס** — שולח את הקישור ב-WhatsApp/SMS/מייל דרך תפריט השיתוף של הטלפון.
- ה-QR מצביע על כתובת העמוד הנוכחית. כדי לנעול כתובת קבועה (למשל לדפוס) — למלא `cardUrl` ב-`CONTACT`.
